# AgentGuard MVP

A lightweight browser-only MVP of AgentGuard, an AI-agent security gateway.

## Demo credentials
No credentials are required. This MVP is intentionally a client-side simulator.

## Demo
1. Open `index.html`.
2. Click **Inspect action** on the preloaded malicious example.
3. Try **Load safe example**.
4. Edit the prompt/tool/action to test the policy engine.

## MVP features
- Prompt-injection detection
- Secret/credential exposure detection
- Destructive operation detection
- Basic exfiltration and PII detection
- Risk score
- ALLOW / HUMAN REVIEW / BLOCK decisions
- Audit log and counters

This is a demonstration prototype, not a production security control.
